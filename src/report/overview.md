# О работе: AI-сервис первичного отбора кандидатов

**Назначение системы:** автоматизация первичного анализа резюме, ранжирование кандидатов на основе соответствия требованиям вакансии и генерация персонализированных вопросов для собеседования.

**Система (SoI):** интеллектуальная система первичного отбора кандидатов, включающая Web UI, сервисы обработки резюме и AI-анализа, а также модуль рекомендаций.

**Основные сценарии:** загрузка резюме, интеллектуальный анализ навыков, сопоставление (matching), ранжирование и генерация вопросов.
