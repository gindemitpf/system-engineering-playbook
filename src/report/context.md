# Контекст и границы

**Цель:** снижение времени HR на первичный скрининг (Screening) и повышение объективности оценки кандидатов.

**Акторы:**
- Кандит: загружает резюме.
- HR: управляет вакансиями, инициирует скрининг.
- Руководитель отдела: утверждает требования, анализирует итоговые рейтинги.
- Администратор: управляет доступом, мониторит работу AI-интеграций.

**Внешние системы:**
- AI Model API (LLM): внешний сервис для обработки естественного языка.
- Storage: облачное хранилище файлов резюме.
